Connect FableFlow to Your Coding Agent Mid-Task

Zero-dependency Model Context Protocol (MCP) server. Fully compatible with Claude Code, Cursor, Codex, and Antigravity.

claude mcp add fable-flow -- npx -y fable-flow
// In .cursor/mcp.json:
{
  "mcpServers": {
    "fable-flow": {
      "command": "npx",
      "args": ["-y", "fable-flow"]
    }
  }
}
// In mcp_config.json:
{
  "mcpServers": {
    "fable-flow": {
      "command": "npx",
      "args": ["-y", "fable-flow"]
    }
  }
}
git clone https://github.com/jastfan/fable-flow.git
cd fable-flow
node mcp-server.js
